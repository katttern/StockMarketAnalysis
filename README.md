# Stock Market Analysis

Торгівля на фондовому ринку повна "шуму" — короткочасних коливань ціни, які не відображають реального тренду. Людське око погано відрізняє справжній розворот від випадкового відхилення. Цей інструмент вирішує саме цю проблему: він математично відокремлює сигнал від шуму та знаходить моменти, коли ціна аномально відхилилась від своєї "природної" траєкторії — що є потенційною точкою входу або виходу.
Замість суб'єктивного "здається, зараз добре купити" — об'єктивний алгоритм з чіткою математичною базою.

# Використані математичні інструменти
1. Експоненційне зважене середнє (EMA)

EMA — це форма зваженого ковзного середнього, де кожне минуле значення має вагу, що спадає за експоненційним законом:

EMA_t = α · P_t + (1 − α) · EMA_{t−1}
 де α = 2 / (window + 1) — коефіцієнт згладжування.

Ціна акції — це зашумлений сигнал. EMA виявляє справжній тренд, реагуючи на нові дані швидше, ніж просте ковзне середнє (SMA), але все одно фільтруючи короткочасні коливання. Це "базова функція" — траєкторія, від якої ми вимірюємо відхилення.

Метод ewm(span=window) з бібліотеки pandas реалізує рекурентну формулу EMA. Параметр span відповідає розміру вікна window і автоматично обчислює α.


2. Чисельне диференціювання — перша та друга похідна

Похідна — це миттєва швидкість зміни функції. Для дискретного ряду чисельна похідна апроксимується центральною різницею:
f'(x_i) ≈ (f(x_{i+1}) − f(x_{i−1})) / 2
Друга похідна — це похідна від першої, тобто швидкість зміни швидкості (прискорення):
f''(x_i) ≈ f'(x_{i+1}) − f'(x_{i−1})

Перша похідна (velocity) — показує напрямок та силу тренду. Додатна → тренд вгору, від'ємна → вниз.

Друга похідна (acceleration) — ключовий фільтр сигналів. Якщо ціна впала нижче норми (BUY-кандидат) і при цьому прискорення > 0 — тренд починає розвертатись вгору. Це підтверджує, що падіння закінчується, і ризик входу знижується.

Використання лише відхилення без прискорення дає багато хибних сигналів: ціна може бути "дешевою" і ще довго падати. Прискорення додає динамічний фільтр.

Функція np.gradient() з бібліотеки NumPy обчислює чисельну похідну методом центральних різниць. На крайніх точках автоматично застосовуються одностороння різниця, щоб уникнути виходу за межі масиву.


3. Статистика відхилень — динамічне стандартне відхилення

Ковзне стандартне відхилення обчислюється у вікні фіксованого розміру, яке "ковзає" вздовж ряду:
σ_t = sqrt( (1/N) · Σ (P_i − μ_t)² )  для i ∈ [t−N, t]
де μ_t — середнє у цьому ж вікні.

Волатильність ринку непостійна: у спокійні дні ціна змінюється мало, під час кризи — різко. Фіксований поріг "відхилення у 10 доларів" буде безглуздим: для тихого ринку це катастрофа, для волатильного — норма.

Динамічний σ вирішує це: поріг сигналу автоматично масштабується під поточну волатильність. Сигнал генерується лише тоді, коли відхилення статистично значуще для поточного стану ринку.

Метод rolling(window).std() з pandas обчислює ковзне стандартне відхилення. min_periods=1 дозволяє коректно обробляти початок ряду, де ще недостатньо даних для повного вікна.


4. Логіка генерації сигналів — перетин усіх трьох концепцій

Три математичні інструменти об'єднуються в одній умові:

BUY-сигнал — одночасно виконуються дві умови:
ціна аномально низька і тренд починає розвертатись вгору

SELL-сигнал — симетрично:
ціна аномально висока і тренд починає розвертатись вниз

Реалізація в коді

buy_signals  = (deviation < -sensitivity * dynamic_std) & (acceleration > 0)

sell_signals = (deviation >  sensitivity * dynamic_std) & (acceleration < 0)

Операції виконуються над масивами NumPy без циклів — це і зручно, і ефективно.
